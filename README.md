# Smarter Scouts

A Civilization VII mod that makes scouts smarter.

## Install
Copy the `smarter-scouts` folder into:

    %LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods

Then enable it in game under **Additional Content → Mods**.

## Status
The mod currently ships a diagnostics-only UI script (`ui/smarter-scouts.js`). Its logs go to the game's Logs folder: `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Logs`.
